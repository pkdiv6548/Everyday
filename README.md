# Everyday Oddities

**The extraordinary hiding in ordinary things.**

A bilingual (English/Hindi), responsive science-discovery website built with plain HTML, CSS and JavaScript. Designed for GitHub Pages with no build step and no external runtime dependencies.

## Pages
- Home: `index.html`
- Explore: `explore.html`
- Topics: Physics, Food Science, Water, Light & Colour, Materials, Sound
- Experiments: `experiments.html`
- About: `about.html`
- Articles: `articles/why-sky-blue.html`, `articles/microwave-works.html`, `articles/water-weird.html`

## Run locally
Open `index.html` in a browser. No package installation required.

## Publish on GitHub Pages
Repository Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save.

All illustrations are original local SVG assets in `assets/`. No external image or script dependencies are required.
