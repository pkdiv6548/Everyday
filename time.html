About these sources

The local and selected world clocks update every second using your device clock and IANA time-zone rules; no time API request is needed. Other public API data is fetched on page load and when you choose Refresh; responses are not cached by this page. If a provider is unavailable or blocks a request, the affected panel shows an error instead of inventing data. Public API availability and rate limits can change.
